# PicnicHealth (PicnicAI)

> PicnicHealth (PicnicAI; legally Mission Health Labs, Inc.) is a San Francisco health-data company and Y Combinator alum (S14, founded 2014). It turns patients' fragmented medical records into structured, research-ready real-world datasets, giving patients a unified view of their care while supplying de-identified, ontology-mapped real-world data to biopharma for non-interventional clinical research.

This file was generated by the API Evangelist enrichment pipeline from the public developer surface. No public REST/OpenAPI product API is published; the primary programmatic surface is a first-party R package.

## Products
- [PicnicHealth (patient product)](https://picnichealth.com/): Unified, complete medical records for patients across every provider.
- [PicnicResearch](https://research.picnichealth.com/): Next-generation non-interventional / real-world-data research for biopharma.

## Data
- Structured and unstructured clinical data extracted and harmonized to standard ontologies: RxNorm, SNOMED, LOINC, ICD.
- R package capabilities: medication history, cohort building, visit-timeline visualization, clinical code mapping, Table 1 generation.
